# Sync Electric System — เว็บไซต์ใหม่

เว็บไซต์บริษัทและ Admin Console สำหรับ **บริษัท ซิงค์ อิเล็คทริค ซิสเต็ม จำกัด**
สร้างใหม่ทั้งหมดด้วย Next.js (แทนที่ระบบ WordPress เดิม)

## สแตกเทคโนโลยี

- **Next.js 16** (App Router, Server Actions)
- **Tailwind CSS 4**
- **Prisma 7** + SQLite (`dev.db`) — เปลี่ยนไปใช้ PostgreSQL ได้ง่ายตอน deploy จริงโดยแก้ `datasource` ใน `prisma/schema.prisma`
- Auth แบบ JWT cookie สำหรับ Admin Console (ไม่ได้ใช้ WordPress admin เดิม)

## เริ่มต้นใช้งาน

```bash
npm install
npx prisma generate
npx prisma migrate dev   # สร้างฐานข้อมูล + ตาราง
npm run seed              # ใส่ข้อมูลตัวอย่าง (หมวดหมู่, สินค้า, แบนเนอร์, ผู้ดูแลระบบ)
npm run dev
```

เปิด http://localhost:3000 สำหรับหน้าเว็บไซต์
เปิด http://localhost:3000/admin/login สำหรับ Admin Console

**บัญชี Admin เริ่มต้น** (สร้างจาก `npm run seed`):

- อีเมล: `admin@sync-electric.com`
- รหัสผ่าน: `SyncAdmin@2026`

> ⚠️ เปลี่ยนรหัสผ่านนี้ทันทีก่อนใช้งานจริง (แก้ไขได้ผ่าน seed script หรือ query ฐานข้อมูลโดยตรง)

## โครงสร้างหลัก

- `src/app/(site)/` — หน้าเว็บไซต์สาธารณะ (หน้าแรก, สินค้า, บทความ, แค็ตตาล็อก, เกี่ยวกับเรา, ติดต่อเรา, สมัคร/เข้าสู่ระบบลูกค้า)
- `src/app/admin/(auth)/` — หน้าล็อกอิน admin
- `src/app/admin/(dashboard)/` — Admin Console (จัดการแบนเนอร์, หมวดหมู่, สินค้า, บทความ, แค็ตตาล็อก, ข้อความติดต่อ, แชทลูกค้า, ใบเสนอราคา, ตั้งค่าเว็บไซต์)
- `prisma/schema.prisma` — โครงสร้างฐานข้อมูล
- `prisma/seed.ts` — ข้อมูลตัวอย่าง/เริ่มต้น

## ระบบแชท + ขอใบเสนอราคา + สมาชิกลูกค้า (ใหม่)

- **แชทหน้าเว็บ** (มุมขวาล่างทุกหน้า) — ผู้เยี่ยมชมที่ยังไม่สมัครสมาชิกจะได้ cookie ประจำเบราว์เซอร์ (`visitor_id`, อายุ 1 ปี) ทำให้แชทเป็นเส้นเดียวต่อเนื่องแม้ปิดเบราว์เซอร์ไปแล้วกลับมาใหม่ ถ้าลูกค้าสมัครสมาชิก/ล็อกอินทีหลัง ระบบจะเชื่อมประวัติแชทเดิมเข้ากับบัญชีให้อัตโนมัติ
- **AI ตอบแชท** (`src/lib/chat-ai.ts`) — ค้นข้อมูลจากตาราง `Product`/`Category` จริงในเว็บมาตอบ (ชื่อสินค้า, สเปค, เปรียบเทียบ) ไม่ใช้ API ภายนอก จึงไม่มีค่าใช้จ่ายเพิ่ม แต่เขียนเป็นฟังก์ชันแยกต่างหาก เปลี่ยนไปเรียก Claude API จริงในอนาคตได้โดยแก้เฉพาะไฟล์นี้ไฟล์เดียว ถ้า AI ตอบไม่ได้ ระบบจะตั้งค่า "ต้องการแอดมิน" ให้ทีมงานเข้ามาตอบต่อที่ /admin/chat
- **ขอใบเสนอราคา** — ปุ่มที่หน้าสินค้าเปิดฟอร์มกรอกข้อมูล บันทึกลงฐานข้อมูล (`/admin/quotes`) และส่งอีเมลแจ้งทีมขายทันที (ดูหัวข้อ SMTP ด้านล่าง)
- **สมาชิกลูกค้า** — สมัคร/เข้าสู่ระบบด้วยอีเมล+รหัสผ่านที่ `/account/register` และ `/account/login`, ดูประวัติคำขอใบเสนอราคาที่ `/account`

### ตั้งค่าการส่งอีเมล (SMTP)

ค่าเริ่มต้นยังไม่ได้ตั้งค่า SMTP — ระบบจะบันทึกคำขอใบเสนอราคาไว้ในเว็บตามปกติ แต่ยังไม่ส่งอีเมลจริง (ดู log ใน terminal และสถานะที่หน้า `/admin/quotes`)

เมื่อพร้อมส่งอีเมลจริง ให้เพิ่มตัวแปรเหล่านี้ในไฟล์ `.env`:

```
SMTP_HOST="smtp.example.com"
SMTP_PORT="587"
SMTP_USER="your-smtp-username"
SMTP_PASS="your-smtp-password"
SMTP_FROM="Sync Electric <noreply@sync-electric.com>"
```

อีเมลปลายทาง (ทีมขาย) ตั้งค่าได้ที่ Admin Console > ตั้งค่าเว็บไซต์ > "อีเมลทีมขาย"

## หมายเหตุเรื่อง Hosting

hosting เดิม (DirectAdmin, PHP + MySQL, FTP) ไม่รองรับ Node.js server ของ Next.js
เมื่อพร้อม deploy จริงต้องใช้ hosting ที่รองรับ Node.js (เช่น VPS, Vercel, Railway) หรือปรับ Prisma ให้ต่อกับฐานข้อมูล PostgreSQL ที่ hosting ใหม่รองรับ
